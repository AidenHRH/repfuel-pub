# 0.23 — the new look and looking back: implementation plan

**Spec:** docs/superpowers/specs/2026-10-24-nutrition-redesign-design.md (Release 0.23) · Executed natively (owner:

## Constraints carried from the code

- Tests press **Log food** and **Log workout** buttons on Summary and expect "Nothing logged yet today": keep those
  accessible names (the + button is "Log food"; Daily habits has a "Log workout" button).
- Tour targets `summary-rings`, `log-food-pill`, `log-workout-pill` stay, on the calories card, the + button and
  the Log workout button.

## Tasks

1. **Ember palette** (`src/theme/tokens.ts`): dark and light values from the spec; `pro` becomes teal (protein),
   accent coral as `accent`/`onAccent` (buttons use `accent` where they used `pro` as the action colour). Contrast
   checked with a small test of the text/background pairs (≥ 4.5:1).
2. **Day status** (`src/domain/dayStatus.ts`): `dayStatus(entries, targets, skipped)` → `{ stage: 'empty' |
   'partial' | 'missed' | 'hit', mealsDone: number }` (fully logged = breakfast, lunch, dinner each logged or
   skipped; hit = protein ≥ target and kcal within ±10%); `streak(stages by day, today)`; `drinksSummary(entries)`
   (items in ml). Repository `daySummaries(db, days)` (entries + the targets in effect that day + skipped meals,
   app_settings `skipped`), `setSkipped(db, day, meal, on)`. Tests first.
3. **Logging for a day**: `logAndAnnounce(…, at?)`; `logTimeFor(day, meal, now)` (today → now; past day → that day
   at the meal's usual time: 08:00, 12:30, 18:30, snack 15:30, drink 12:00); `day` route param carried by the Log
   food flow (FoodLogger, food/log, food/new, scan, TileRow, Build a meal). `logAgain(db, entryId, meal, now)`
   copies an entry to today. Tests.
4. **Workout sessions** (`src/domain/sessions.ts`): `groupSessions(items, overrides)` → sessions (60-minute rule,
   classes alone, name from muscle groups, start time); overrides in app_settings `sessionBreaks`
   (`{ [workoutId]: 'join' | 'split' }`). Route `session/[id]` (id = first workout id) shows exercises, sets, effort,
   PRs. Workouts tab groups a day's lifts into session cards; hold a lift → Move to previous session / Start new
   session. Tests.
5. **Summary** rewrite (`src/app/(tabs)/index.tsx` + `src/features/summary/*`): Today ▾ with a day picker (last 5
   weeks), streak badge, week dots (tap → that day; tap the row label → week view sheet with protein/kcal per day),
   calories card, macro card, drinks chip (tap → list), Meals (Breakfast … Drinks) each with total, entries (photo
   thumbnail when the food has one), Log (→ log-food?meal=&day=), "Skipped" toggle for breakfast/lunch/dinner on
   past days and today after its time; hold an entry → Log again (meal pills); Daily habits (creatine, today's
   sessions, Log workout); + button. Past days show the same with "‹ Today" to return. Tests.
6. **Shuffle fix** (`mealPlanRepository.planInputs`): drop owner recipes whose name matches a template. Test.
7. Release 0.23.0: docs, version, check, push, build check.
